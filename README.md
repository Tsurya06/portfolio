# Developer Portfolio

A modern, responsive, and performance-focused personal portfolio website built with React, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- **Interactive Hero & 3D Interactive Mascot**: Smooth animations with custom hover interactions and particles.
- **Dynamic Starfield Galaxy Background**: Procedural starry galaxy canvas with twinkle and parallax effects.
- **Curated Projects Showcase**: Filterable portfolio project cards with live demo links and tech tags.
- **Skills Matrix & Experience Timeline**: Interactive showcase of skills categorized by domain and interactive career history.
- **Client Testimonials & Contact Form**: Clean feedback cards and working contact section with validation.
- **Theme Support & Smooth Scroll**: Dark/light mode switching and spring-animated scroll progress bar.
- **Responsive & Accessible**: Fully responsive layouts optimized for all screen sizes and mobile touch devices.

## Tech Stack

- **Framework**: [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn / pnpm

### Installation

```bash
# Clone the repository
git clone <repository-url>

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Build for Production

```bash
npm run build
npm run preview
```
